# Observer Fleet Manifest v0.2

## Two kinds of ships

### 1. Generic observer ships

These do not know the exact generator. They search for broad structure:

- digit-frequency imbalance
- compression
- modular recurrence
- prime-digit gap anomalies
- Fourier/wave coherence
- ARP adaptive memory
- Phase-Lift step coherence

### 2. Witness ships

These are hypothesis-testers. A witness ship asks:

> Does this landscape match the output of a proposed generator?

A witness ship does not discover the generator by itself.

It confirms or rejects a named hypothesis.

## Rule

Generic ships explore.

Witness ships testify.

A serious Observer Fleet should use both:

- Generic fleet: detects that something is non-random.
- Witness fleet: tests what generator could explain it.

## Mission lesson

Fibonacci digits may look random-like to a generic fleet at a short horizon.

A Fibonacci witness ship can still confirm the Fibonacci generator.

This is not cheating if labeled honestly: it is hypothesis testing, not blind discovery.
